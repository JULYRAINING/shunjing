**顺景·石上清泉项目****资产情况**

项目本体

顺景·石上清泉项目位于北京市朝阳区东四环与北四环交口处，是四环内唯一被城市永久绿化带包围的豪宅项目。项目整体采用上浮式建筑设计，总占地面积43.12万平米，总建筑面积18.24万平米，其中住宅面积7.06万平米，商业面积8.46万平米，车库面积2.72万平米。项目已完成开发建设，五证齐全且均已竣工验收。住宅部分已售1.93万平米，剩余可售住宅面积为5.13万平米。

项目资产

项目共14栋建筑单体，共计住宅127套，第1栋、6栋、7栋与8栋共计31套面积约1.93万平米已售出并交付，剩余96套住宅，面积约5.13万平米。其中第2栋、3栋为独栋建筑；第4栋、5栋为一梯一户；第9栋为三梯两户；第10栋、11栋与12栋为两梯两户；第13栋为三梯四户；第14栋为两梯四户。

项目剩余其他可售资产为：

（1）商业面积为8.46万平米，其中地下综合（-201、-202）：面积为32092.94㎡，分为三个部分：①顺峰餐饮，大概8400㎡；②温泉酒店，大厅区域及104间客房，18000㎡左右；③温泉（VIP+普通）部分，大概在6000㎡。地下水世界（温泉）（-301、-302）：面积为52531.76㎡。

（2）车库（负一层，实际二层）：面积2.72万平米，车位533个。
